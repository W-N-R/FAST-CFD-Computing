# FAST NUCES CFD — Computing Archive (Faisalabad Campus)

Past papers, notes, slides, assignments and lab material for the **BS Computing**
program at **FAST-NUCES, Faisalabad (CFD)** campus, organized by semester.

This repository is the Faisalabad data source for the **FAST ATM** app — the app
browses it directly, so the folder layout below matters.

## 📁 Structure

```
1st Semester/   Programming Fundamentals, Calculus, Applied Physics, DLD, ...
2nd Semester/   OOP, Communication & Presentation Skills, ...
3rd Semester/   Data Structures, COAL, Discrete Structures, ...
4th Semester/   Algorithms, Database Systems, Operating Systems, ...
5th Semester/   Theory of Automata, Software Design & Analysis, Computer Networks, ...
6th Semester/   ...
PAST PAPERS/    Cross-semester past-paper collections
```

Inside each course: `Notes/`, `Past Papers/`, `Assignments/`, `Slides/`, `Books/`, etc.

## 🤝 Contributing

Material is contributed by the FAST Faisalabad student community — directly here,
or through the in-app upload flow (every upload becomes a reviewed Pull Request).
